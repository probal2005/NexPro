# Projects built with NexPro

Each program reads one line of JSON and prints one JSON result. The program source is in `.pa` files. Use NexPro 4.9 or later to run every project below. In the [live playground](https://nexpro-playground.vercel.app/), open **Examples → NexPro projects** to load a program, its sample input, and any modules automatically.

| Project | What it does | Live demo |
| --- | --- | --- |
| [Group Expense Settlement](expense-settlement/) | Equalizes contributions and reports who should pay whom. | [Open](https://nexpro-playground.vercel.app/projects/expense-settlement/) |
| [Freelance Quote Generator](freelance-quote/) | Converts hours, rates, and a discount into an itemized quote. | [Open](https://nexpro-playground.vercel.app/projects/freelance-quote/) |
| [Student Report Card](student-report-card/) | Ranks valid students and reports empty or out-of-range score lists. | [Open](https://nexpro-playground.vercel.app/projects/student-report-card/) |
| [Inventory Reorder Report](inventory-reorder/) | Flags items at or below minimum stock and calculates reorder quantities. | [Open](https://nexpro-playground.vercel.app/projects/inventory-reorder/) |
| [Monthly Budget Checker](monthly-budget/) | Shows remaining or overspent amounts by category and overall. | [Open](https://nexpro-playground.vercel.app/projects/monthly-budget/) |
| [Order Dispatch Checker](order-dispatch/) | Separates ready orders from orders that need attention. | [Open](https://nexpro-playground.vercel.app/projects/order-dispatch/) |
| [Contact List Cleaner](contact-cleaner/) | Trims contact fields and identifies duplicate or incomplete rows. | [Open](https://nexpro-playground.vercel.app/projects/contact-cleaner/) |
| [Quiz & Score Tracker](quiz-score/) | Scores answers and reports mistakes and unanswered questions. | [Open](https://nexpro-playground.vercel.app/projects/quiz-score/) |
| [Work Hours & Overtime Report](overtime-report/) | Totals weekly hours and estimates base and overtime pay. | [Open](https://nexpro-playground.vercel.app/projects/overtime-report/) |
| [Tournament Standings](tournament-standings/) | Builds a league table from teams and recorded scores. | [Open](https://nexpro-playground.vercel.app/projects/tournament-standings/) |

[Open the Bill Splitter](https://nexpro-playground.vercel.app/projects/bill-splitter/) for an additional live demo.
