# Projects built with NexPro

Each program reads one line of JSON and prints one JSON result. The program source is in `.pa` files. Use NexPro 3.0 or later. In the [live playground](https://nexpro-playground.vercel.app/), open **Examples → NexPro projects** to load a program, its sample input, and any modules automatically.

| Project | What it does |
| --- | --- |
| [Group Expense Settlement](expense-settlement/) | Equalizes contributions and reports who should pay whom. |
| [Freelance Quote Generator](freelance-quote/) | Converts hours, rates, and a discount into an itemized quote. |
| [Student Report Card](student-report-card/) | Ranks valid students and reports empty or out-of-range score lists. |
| [Inventory Reorder Report](inventory-reorder/) | Flags items at or below minimum stock and calculates reorder quantities. |
| [Monthly Budget Checker](monthly-budget/) | Shows remaining or overspent amounts by category and overall. |
| [Order Dispatch Checker](order-dispatch/) | Separates ready orders from orders that need attention. |
| [Contact List Cleaner](contact-cleaner/) | Trims contact fields and identifies duplicate or incomplete rows. |
| [Quiz & Score Tracker](quiz-score/) | Scores answers and reports mistakes and unanswered questions. |
| [Work Hours & Overtime Report](overtime-report/) | Totals weekly hours and estimates base and overtime pay. |
| [Tournament Standings](tournament-standings/) | Builds a league table from teams and recorded scores. |

For a separate browser-form demo, see the existing [Bill Splitter](bill-splitter/).
