# NexPro Programming Language

## Version

0.3.0

---

# Usage

Run a NexPro file

```bash
nexpro run examples/hello.pa
```

---

# Commands

## Run

```bash
nexpro run file.pa
```

Example

```bash
nexpro run examples/math.pa
```

---

## Version

```bash
nexpro version
```

Output

```
NexPro 0.3.0
```

---

## Help

```bash
nexpro help
```

```
.pa
```

- CLI

# Examples

```pa
name = "Probal"

say name
```

Output

```
Probal
```

---

```pa
a = 10

b = 20

say a + b
```

Output

```
30
```
