# 01. প্রথম .pa প্রোগ্রাম

[কোর্স সূচি](README.md) · [পরের পাঠ →](02-variables.md)

NexPro সোর্স হলো UTF-8 টেক্সট, সাধারণত `.pa` ফাইলে রাখা হয়।

## ধরন ও সিনট্যাক্স

| ধরন | সিনট্যাক্স | সংজ্ঞা |
|---|---|---|
| কমেন্ট | `# note` | লাইনের শেষে পর্যন্ত ব্যাখ্যা |
| আউটপুট | `say expression` | মান দেখায় ও নতুন লাইন দেয় |
| স্ট্রিং | `"Hello"` | উদ্ধৃতির মধ্যে লেখা |

## কখন এবং কেন ব্যবহার করবে

Playground-এ কোড পেস্ট করে Run code চাপো। টার্মিনালে hello.pa নামে সেভ করে nexpro run hello.pa চালাও।

**সুবিধা।** সরাসরি ফল দেখা যায়, তাই ছোট হিসাব দিয়ে শুরু করা সহজ।

**সীমাবদ্ধতা ও সাধারণ ভুল।** নামের বড় ও ছোট হাতের অক্ষর আলাদা। উদ্ধৃতির ভেতরের # টেক্সটের অংশ।

## চালিয়ে দেখো

কোডটি [Playground](https://nexpro-playground.vercel.app/)-এ পেস্ট করে **Run code** চাপো। [উদাহরণের .pa ফাইল](examples/01-first-program.pa)

```text
# প্রথম প্রোগ্রাম
say "Hello, NexPro!"
say 2 + 3
```

**প্রত্যাশিত ফল**

```text
Hello, NexPro!
5
```
